# Tasteology — Day 02

**Independent frontend café concept · 100-Day Local Business Website Challenge**

[Live demo](https://patu-art.github.io/DAY-2/) · [Portfolio](https://patu-art.github.io/Portfolio/) · [Challenge log](https://patu-art.github.io/Portfolio/challenge.html)

This is an independent demonstration website inspired by Tasteology in Birmingham. It is not an official business website, paid client commission or endorsement.

## Development focus

- Responsive semantic HTML, CSS and vanilla JavaScript.
- Ingredient-led editorial typography and visual storytelling.
- Menu, gallery, venue information and interactive navigation.
- A design exercise in balancing rich presentation with mobile usability.

## Project files

- `index.html` — page content and semantic structure.
- `style.css` — design and responsive styling.
- `script.js` — browser interactions.
- `assets/` — local project assets.

## Running the site

Open `index.html` with VS Code Live Server or another local HTTP server. The GitHub Pages demo uses static frontend files; there is no backend or ordering system.

**Asset caveat:** The page currently references at least one remotely hosted third-party photograph. Availability, image rights and usage permissions are not guaranteed by this repository. For an official launch, verify venue details with the owner, obtain approved photographs and self-host authorized optimized assets.
